# AI Artisans Books (Telegram Mini App)

The phone version of the AI Artisans Books page, opened from the company's Telegram receipts bot.
This repository holds only the page's code. It contains no data: the books are read through a
private Google Apps Script that accepts requests signed by Telegram for one account only.

Built from the books page by `miniapp/build.py` in the receipts-bot repository. Don't edit `index.html` here.
